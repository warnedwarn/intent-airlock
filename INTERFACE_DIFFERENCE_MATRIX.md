# Interface difference matrix

| Dimension | Intent Airlock | Risk Archipelago |
|---|---|---|
| Input journey | Mission drawer, then staged open, request, consume controls | A single field-note tray dropped directly onto a living map |
| Spatial composition | Radar bay beside a vertical flight-strip board | Edge-to-edge ocean canvas with scattered islands and a bottom survey sheet |
| Primary action | Request one clearance against cumulative quotas | Sound one observation against the whole existing map |
| Result | Category quota ring changes and an execution strip | A new island appears, an island deepens, or an echo marker fades |
| Motion | Continuous radar sweep and pulsing blips | Slow water drift, island rise, and expanding depth contours |
| Typography | Monospace telemetry plus compressed control-room display | Editorial serif labels plus hand-noted field annotations |
| Palette | Near-black, mint, acid yellow | Salt paper, ultramarine, coral, kelp green |
